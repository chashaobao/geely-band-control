## 功能条件

- **映射已填入（图标除外）**：小组件绑定后，4 个槽位按容器名识别；车锁/车窗功能已确认，kjck/ccqk 需车主手动标记；车况自动读取按已填字段名工作；图标自动识别不可用（候选选择器集待真机目视比对）。
- 按钮是否可用由车主授权、卡片数据、动作方向和加载状态共同决定。「指令已发送」表示已调用官方按钮，车辆最终结果需查看官方车况。开关方向以当前图标与有效车况为依据。
- 领克的锁是**单按钮切换**（开锁/关锁同一按钮），不要按银河的双图标逻辑判断锁态；以领克 App 的当前锁态与卡片回显为准。
- 手机后台和锁屏通信受系统省电策略影响。绑定后检查更新时间，依次验证前台、后台和锁屏连接。
